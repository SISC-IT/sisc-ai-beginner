# 개인 프로젝트: 나만의 AI 주식 매매전략 만들기

## 1. 프로젝트 소개

기존에 제공된 AI 주식 매매 코드를 바탕으로 각자 원하는 부분을 자유롭게 수정하여 자신만의 매매전략을 만드는 개인 프로젝트입니다.

수정한 코드로 백테스트를 진행한 뒤, 기존 전략과 수정 전략의 결과를 비교·분석합니다.

프로젝트는 복잡하게 구성하지 않고 **파이썬 파일 1개**로 완성합니다.

---

## 2. 프로젝트 목표

- 기존 AI 주식 매매 코드의 구조 이해
- 자신만의 매매 아이디어 설계
- 매매전략을 코드에 직접 적용
- 백테스트를 통한 전략 성과 확인
- 기존 전략과 수정 전략의 차이 분석

> 수정한 전략의 수익률이 기존 전략보다 높아야 하는 것은 아닙니다.  
> 어떤 부분을 왜 수정했고, 그 결과가 어떻게 달라졌는지 분석하는 것이 중요합니다.

---

## 3. 진행 방법

1. 기존 코드를 실행합니다.
2. 기존 전략의 백테스트 결과를 기록합니다.
3. 코드에서 원하는 부분을 자유롭게 수정합니다.
4. 수정한 코드로 다시 백테스트를 진행합니다.
5. 기존 전략과 수정 전략의 결과를 비교합니다.
6. 결과가 달라진 이유를 간단하게 분석합니다.

---

## 4. 수정 가능한 항목

다음 항목 중 원하는 내용을 **하나 이상** 자유롭게 수정하면 됩니다.

- 매매 종목 변경
- 학습 데이터 기간 변경
- 입력 시퀀스 길이 변경
- 기술적 지표 추가 또는 삭제
- LSTM·Transformer 모델 설정 변경
- 학습 횟수 또는 배치 크기 변경
- 매수·매도 조건 변경
- 매수 확률 기준 변경
- 손절·익절 조건 추가
- 초기 투자금 변경
- 종목별 투자 비중 변경
- 그 외 자신이 생각한 새로운 매매전략 적용

### 수정 예시

```python
# 매매 종목 변경
ticker = "AAPL"
ticker = "NVDA"

# 매수 확률 기준 변경
buy_threshold = 0.5
buy_threshold = 0.65

# 입력 시퀀스 길이 변경
sequence_length = 30
sequence_length = 60
```

위 예시는 참고용이며, 반드시 동일하게 수정할 필요는 없습니다.

---

## 5. 프로젝트 조건

- 개인별로 자유로운 전략을 구성합니다.
- 기존 코드에서 최소 한 가지 이상을 수정합니다.
- 수정한 코드로 백테스트를 실행합니다.
- 기존 전략과 수정 전략의 결과를 비교합니다.
- 프로젝트 결과물은 파이썬 파일 1개로 구성합니다.

---

## 6. 결과 비교

다음 항목 중 자신의 전략을 설명하는 데 필요한 항목을 선택하여 비교합니다.

- 최종 수익률
- 누적수익률
- 거래 횟수
- 승률
- 최대 손실폭
- 최종 자산
- 매수·매도 시점
- 누적수익률 그래프

모든 항목을 반드시 사용할 필요는 없습니다.

### 비교표 예시

| 구분 | 기존 전략 | 수정 전략 |
|---|---:|---:|
| 최종 수익률 | 10.5% | 14.2% |
| 최종 자산 | 11,050,000원 | 11,420,000원 |
| 거래 횟수 | 32회 | 18회 |
| 승률 | 53.1% | 61.1% |
| 최대 손실폭 | -12.4% | -8.7% |

---

## 7. 결과 분석

다음 내용을 중심으로 간단하게 작성합니다.

### 수정한 내용

- 코드에서 어떤 부분을 수정했는가?
- 기존 설정을 어떤 값으로 변경했는가?

### 수정한 이유

- 해당 부분을 수정한 이유는 무엇인가?
- 어떤 결과를 예상했는가?

### 결과 비교

- 기존 전략과 비교하여 어떤 차이가 발생했는가?
- 수익률, 거래 횟수 또는 손실폭이 어떻게 변했는가?

### 결과 해석

- 예상한 결과와 실제 결과가 일치했는가?
- 결과가 달라진 원인은 무엇이라고 생각하는가?
- 전략의 장점과 한계는 무엇인가?

---

## 8. 제출물

다음 결과물을 제출합니다.

### 필수 제출물

- 수정한 파이썬 파일 1개
- 기존 전략과 수정 전략의 백테스트 결과
- 수정한 부분과 수정 이유
- 결과에 대한 간단한 분석

### 파일명

```text
학번_이름_개인프로젝트.py
```

예시:

```text
21011384_석재빈_개인프로젝트.py
```

## 9. 코드 작성 예시

파이썬 파일 안에 수정 내용과 분석 결과를 주석으로 작성할 수 있습니다.

```python
"""
AI 주식 매매전략 개인 프로젝트

이름:
학번:

1. 수정한 내용
- 매매 종목을 AAPL에서 NVDA로 변경
- 매수 확률 기준을 0.5에서 0.65로 변경

2. 수정한 이유
- NVDA의 높은 변동성이 전략 성과에 미치는 영향을 확인하기 위해 변경
- 확실한 상승 신호에서만 매수하도록 확률 기준을 높임

3. 결과 비교
- 기존 전략 수익률:
- 수정 전략 수익률:
- 기존 전략 거래 횟수:
- 수정 전략 거래 횟수:

4. 결과 분석
- 매수 기준을 높이면서 거래 횟수는 감소했지만 잘못된 매수 신호도 감소함
- 다만 일부 상승 구간에 진입하지 못하는 한계가 발생함
"""
```

---

## 10. 유의사항

- 코드를 수정한 후 정상적으로 실행되는지 확인합니다.
- 기존 결과와 수정 결과를 혼동하지 않도록 구분합니다.
- 다른 사람의 코드를 그대로 복사하지 않습니다.
- 결과가 좋지 않더라도 임의로 수치를 변경하지 않습니다.
- 좋은 수익률보다 수정 과정과 결과 분석을 중요하게 평가합니다.
